# Fonts

The specification (§3.4) names two families, both from Indian Type Foundry, and says they
should not be swapped for Inter, Poppins, Manrope, DM Sans or a system stack.

| Family | Weights | Status in this build |
|---|---|---|
| **Switzer** | 400, 500, 600 | Shipped. `switzer-400.woff2`, `switzer-500.woff2`, `switzer-600.woff2` — the Latin subset, self-hosted. |
| **Gambetta Italic 400** | 400 italic | **Not shipped.** See below. |

Total shipped: 4 files, 57 KB — inside the §12 budget of ≤ 4 files and ≤ 180 KB.

## Gambetta is missing, and why

Gambetta appears exactly once on the whole site: the founder's signed line in §8.10.
Fontshare (`api.fontshare.com`, `cdn.fontshare.com`) is blocked by this build environment's
egress policy, and Gambetta is not published to npm, so the file could not be fetched.

Per §11 the missing asset is flagged rather than substituted. The `@font-face` rule, the
`--font-signature` token and the one `font-style: italic` usage are all already wired and
correct. To finish it:

1. Download Gambetta Italic 400 from https://www.fontshare.com/fonts/gambetta
2. Save the WOFF2 as `public/fonts/gambetta-italic.woff2`

No code change is needed. Until then that one line falls back through the stack to Switzer.

## The rupee sign

The only Switzer build reachable from npm (`@carrot-kpi/switzer-font`, generated by the
Fontsource tooling) is a Latin subset of 385 glyphs and **does not contain U+20B9 ₹**.
The price is the money shot of §8.11, so a fallback to the OS UI font was not acceptable.

`rupee-inter-var.woff2` is Inter Variable subset to the single glyph U+20B9 (1.2 KB),
declared as its own family `HUMAN Rupee` with `unicode-range: U+20B9` and placed after
`Switzer` in the stack. Switzer renders every other character; the browser falls through to
this one file for ₹ alone. Inter is SIL OFL 1.1 — see `LICENSE-Inter.txt`. Keeping it a
separate family, rather than aliasing it as "Switzer", keeps that licence intact.

When a full Switzer (which does contain ₹, as an Indian foundry's typeface would) is
obtained from Fontshare, drop it in, delete the `HUMAN Rupee` `@font-face` block in
`src/styles/base.css`, and remove `'HUMAN Rupee'` from `--font-sans`.

## Tabular figures

§3.4 requires tabular lining figures everywhere so digits never jitter during a count-up.
Switzer's digits are **tabular by default** — every digit has an advance of 576/1000 units —
so this is structurally guaranteed, not just requested. `font-variant-numeric: tabular-nums
lining-nums` is set on `body` as well, which covers the fallback stack.

## Metric-matched fallback

§6.1 requires that no headline reflows on font load. `Switzer Fallback` in `base.css`
overrides Arial/Helvetica's metrics to Switzer's own (upem 1000, ascender 980, descender
−250, x-height 533) via `size-adjust`, `ascent-override` and `descent-override`, so the text
box is the same size before and after the swap.
